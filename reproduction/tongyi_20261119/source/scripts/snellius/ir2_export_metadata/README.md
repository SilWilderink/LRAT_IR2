# Tongyi-supervised LRAT reproduction — 19 November 2026

This folder preserves the Snellius reproduction, its executed evidence, and both trained retrievers. The retrievers were fine-tuned on **released LRAT-Train pairs generated by the original authors using Tongyi DeepResearch trajectories on InfoSeekQA seed questions**. We did not regenerate the training trajectories or fine-tune the agent.

| Retriever | Benchmark | Correct | Success rate |
| --- | --- | ---: | ---: |
| Qwen3-Embedding-0.6B + LRAT | BrowseComp-Plus | 173/830 | 20.84% |
| Multilingual-E5-Large-Instruct + LRAT | BrowseComp-Plus | 218/830 | 26.27% |
| Qwen3-Embedding-0.6B + LRAT | InfoSeek-Eval | 200/300 | 66.67% |
| Multilingual-E5-Large-Instruct + LRAT | InfoSeek-Eval | 216/300 | 72.00% |

All four completed evaluations use the fixed Tongyi-DeepResearch-30B-A3B agent. Qwen trained on one A100 with batch/group 2/2; E5 trained on one A100 with batch/group 32/10 and sub-batches of eight. Both used two epochs, learning rate 1e-6, maximum query/passage length 512 and temperature 0.02. These differ from the paper/released multi-GPU recipe; no base-retriever baseline comparison was completed.

## Contents

- `source/`: runnable source snapshot, including Snellius scripts, both environment manifests/locks, modified FlagEmbedding code, and documentation. Start with [the experiment report](source/docs/experiment_report.md). `source-changes.patch` records tracked edits relative to the source Git commit.
- `artifacts/tongyi-browsecomp-plus/<retriever>/model/`: standalone trained weights, tokenizer and configuration. Use the adjacent `retrieval.json` for pooling, normalization and query formatting. `provenance/` contains training logs, trainer state, environment lock and run configuration; `evaluation/` contains scores and compressed trajectories/judgments/executed source.
- `artifacts/training-checkpoints/<retriever>/checkpoint-<step>/`: complete final checkpoints, including weights, optimizer, scheduler and RNG state (Qwen step 96502; E5 step 6030).
- `artifacts/tongyi-infoseek/<retriever>/`: both completed InfoSeek reports and compressed per-question trajectories/judgments, plus run metadata and executed source.
- `artifacts/browse-audit/`: document-label audit, including review CSV, examples and compressed browsing events.
- `artifacts/failed-agent-matrix/`: configuration, frozen source and startup logs for all eight failed WebExplorer/AgentCPM trials. They produced no benchmark scores; their judge jobs were cancelled. `job-status.txt` records Slurm states.
- `results-summary.json`: portable relative paths to the four score reports and trained model directories.
- `manifest.json` and `SHA256SUMS`: source provenance and checksums for the package.

## Git and artifact storage

This folder belongs to local branch `Reproduction_results`. Scripts, reports, compressed evaluation audits and manifests are committed. Multi-gigabyte `*.safetensors` and `optimizer.pt` files, plus RNG/training-argument binary files, are physically copied here but excluded from Git by this folder's `.gitignore`. A Git clone alone therefore does not contain the full model/checkpoint artifacts. Transfer this directory with `rsync -a` to preserve all files, then verify with `sha256sum -c SHA256SUMS` through a Slurm staging job on Snellius. No Git remote push is performed by the export.

Canonical datasets remain in permanent storage at `/home/scur0901/datasets/lrat`; indexes, caches, installed environments and downloaded agent/judge weights are excluded. Historical absolute paths inside original reports remain unchanged. Prefer `results-summary.json` for the copied models and reports.

To use the scripts, set `LRAT_REPO_ROOT` to this folder's `source` directory before sourcing `source/scripts/snellius/env.sh`; configure account/storage paths through a new ignored `source/scripts/snellius/local.sh`. Run training, inference, indexing and GPU checks through Slurm. Source snapshots preserve the original implementation, including the unresolved GPU startup problem in the eight additional trials.
